      AI Settings

      Text AI

      Multiple text providers are supported. Each provider has a saved default model; you can temporarily choose another model when adding words.

      Security

      API keys are stored in this browser's local storage for this app. Do not use this on a shared/public device. Requests are sent through the app proxy over HTTPS.

      Add New Word with AI

      Choose the Text AI provider and model for this generation. The selection is temporary and does not change the provider's saved default.

      Model list is loaded from the selected provider. Custom model is temporary too.

      Generate Visual with Image AI

      Choose the Image AI provider and model for this image only. Your saved provider default will not be changed.

      For providers such as Pollinations, use an image model such as flux, gptimage, or another model returned by the provider.

      Add AI Provider

      Use an OpenAI-compatible HTTPS endpoint. Text and Image providers are configured separately.
